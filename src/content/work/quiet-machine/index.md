challenge: >-
  A hospitality group receives bookings, function enquiries, lost property and
  complaints through one shared inbox. High-value enquiries wait behind routine
  ones, replies depend on who is on shift, and nobody can say which questions
  come up most.
approach: >-
  Automate the sorting and the first draft, never the final word. Each message
  is classified, prioritised and routed to the right person with a suggested
  reply built from approved policies. Sensitive messages, such as complaints,
  skip the draft and go straight to a human.
developed:
  - Classification of each enquiry by type, urgency and value
  - Routing rules that send each type to the right person or team
  - Draft replies built only from approved policies and current information
  - A human approval step before anything is sent
  - A weekly summary of enquiry themes, response times and gaps in the knowledge base
map:
  outside:
    - Faster, consistent replies to guests
    - Function enquiries answered while the guest is still deciding
    - Complaints handled personally by a manager
  inside:
    - Classifier and routing rules
    - Approved policy library for drafts
    - Approval queue and weekly themes report
objectives:
  - Shorten first-response times, measured against the current baseline
  - Stop high-value function enquiries getting lost in the queue
  - Give staff time back from repetitive replies
seoDescription: Concept project with an interactive demo. AI enquiry triage for hospitality, with classification, routing, drafted replies and human approval.
